# CS61A: Structure and Interpretation of Computer Programs

## Overview
This repository contains my work for UC Berkeley's CS61A course: Structure and Interpretation of Computer Programs. The course focuses on programming paradigms, abstraction techniques, and introduces fundamental computer science concepts using Python, Scheme, and SQL.

## Course Information
* **Course**: CS61A: Structure and Interpretation of Computer Programs
* **Institution**: University of California, Berkeley
* **Term**: Fall 2024
* **Website**: [https://cs61a.org/](https://cs61a.org/)

## Repository Structure
```
.

├── projects/          # Major course projects
│   ├── hog/           # Game of Hog project
│   ├── cats/          # Typing test project
│   ├── ants/          # Ants vs. SomeBees game
│   └── scheme/        # Scheme interpreter
└── discussions/       # Discussion worksheets and solutions
```

## Projects
The course includes several substantial programming projects:

1. **The Game of Hog**: A simulator and multiple strategies for the dice game Hog
2. **Cats**: A typing speed test implementation with autocorrect functionality
3. **Ants vs. SomeBees**: A tower defense game inspired by Plants vs. Zombies
4. **Scheme Interpreter**: An interpreter for a subset of the Scheme language

## How to Run the Code
Most assignments are designed to run with Python 3. To run Python files:
```bash
python3 filename.py
```

For specific projects, check the included README files in each project directory for detailed instructions.
